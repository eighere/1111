# AI를 생각의 스파링 상대로 쓰는 프롬프트 모음

> 원칙: **AI가 대신 생각하게 하지 않고, 내 생각을 단련하게 한다.**
> 모든 프롬프트는 내가 먼저 쓴 글이나 생각을 붙여 넣는 것에서 시작한다.

## 왜 이 방식이어야 하나: 연구가 보여 주는 것

| 연구 | 발견 | 의미 |
|---|---|---|
| **Bastani 외 (2024)**, 튀르키예 고등학생 약 1,000명 현장 실험 | 일반 GPT-4를 쓴 학생은 연습 문제 성적이 48% 올랐지만, AI 없이 본 시험에서는 AI를 안 쓴 학생보다 **17% 낮았다.** 답을 바로 주지 않고 힌트만 주도록 설계한 "GPT 튜터"를 쓴 집단은 이런 손해가 거의 없었다. | AI가 답을 주면 실력이 줄 수 있다. **AI가 질문하고 힌트를 주게** 하면 이를 막을 수 있다. |
| **Lee 외 (2025)**, 마이크로소프트·카네기멜런, 지식 노동자 319명 설문 | AI를 더 신뢰할수록 비판적 사고를 덜 했고, **자기 능력을 더 신뢰할수록** 비판적 사고를 더 했다. | AI 결과를 검토하고 반박하는 습관을 의도적으로 만들어야 한다. |
| **Kosmyna 외 (2025)**, MIT 미디어랩 "Your Brain on ChatGPT" (사전 공개 논문, 참가자 54명) | 처음부터 ChatGPT로 에세이를 쓴 집단은 뇌 연결성이 가장 낮았고 자기가 쓴 글을 거의 인용하지 못했다. 먼저 스스로 쓰고 나중에 AI를 쓴 집단은 상대적으로 높은 뇌 활동을 보였다. | 순서가 중요하다. **먼저 내가, 그다음 AI.** (표본이 작고 동료 심사 전이라 참고 수준으로 본다) |
| **Gerlich (2025)**, 666명 설문 | AI 도구를 많이 쓰고 생각을 AI에 넘기는 정도(인지적 오프로딩)가 높을수록 비판적 사고 점수가 낮았다. | 상관관계라 인과는 아니지만 방향은 위와 같다. |

## 사용법

1. 생각 노트, 결정 일지, 에세이 초안 등 **내가 먼저 쓴 것**을 준비한다.
2. 아래 프롬프트 중 하나를 골라 `[ ]` 부분을 채워 붙여 넣는다.
3. AI의 질문에 **AI 없이 내가 답한다.** 답을 다시 노트에 옮긴다.

### 모든 프롬프트 앞에 붙이는 기본 규칙 (선택)

```
너는 내 생각을 단련시키는 스파링 상대야. 다음 규칙을 지켜 줘.
- 내 글을 대신 다시 써 주지 마. 질문하고 지적만 해.
- 칭찬은 한 줄 이하로. 약점에 집중해.
- 내가 답을 달라고 명시적으로 요청하기 전에는 정답을 말하지 마.
- 한 번에 질문은 최대 3개까지만 해.
```

## A. 생각을 선명하게 (매일 생각 노트와 함께)

### A1. 소크라테스식 질문
**근거:** Richard Paul의 소크라테스식 질문 6유형 (Paul & Elder, *The Thinker's Guide to the Art of Socratic Questioning*, 2006)

```
아래는 내 생각이야.
[내 생각 붙여 넣기]

소크라테스식 질문 6가지 유형으로 나에게 질문해 줘. 유형마다 하나씩, 총 6개.
1. 명확화: 내가 정확히 무슨 뜻으로 말했는지
2. 전제: 내가 당연하다고 여긴 것
3. 근거와 증거: 무엇을 보고 그렇게 생각하는지
4. 관점: 다른 사람은 어떻게 볼지
5. 함의와 결과: 이 생각이 맞다면 무엇이 따라오는지
6. 질문에 대한 질문: 애초에 이게 좋은 질문인지
답은 내가 할 테니 질문만 해 줘.
```

### A2. 설명 깊이 점검
**근거:** 설명 깊이의 착각 (Rozenblit & Keil, 2002); 자기 설명 효과 (Chi 외, 1989)

```
나는 [주제]를 이해하고 있다고 생각해. 아래는 내 설명이야.
[내 설명 붙여 넣기]

1. 내 설명에서 "어떻게"가 빠진 채로 넘어간 단계를 찾아서 표시해 줘.
2. 그 단계마다 "그게 정확히 어떻게 일어나는데?"라고 물어 줘.
3. 내가 전문 용어로 얼버무린 곳이 있으면 쉬운 말로 다시 설명하라고 요구해 줘.
```

### A3. 인출 퀴즈
**근거:** 인출 연습 효과 (Roediger & Karpicke, 2006)

```
지난주에 내가 쓴 생각 노트들이야.
[노트 붙여 넣기]

이 내용으로 나에게 퀴즈를 5개 내 줘. 단순 암기가 아니라
"이 생각을 [새로운 상황]에 적용하면?" 같은 응용 질문으로.
한 번에 하나씩 내고, 내가 답하면 피드백한 뒤 다음 문제로 넘어가 줘.
```

## B. 판단력 단련 (결정 일지와 함께)

### B1. 사전 부검
**근거:** Gary Klein (2007); Mitchell, Russo & Pennington (1989)

```
나는 [결정 내용]을 하기로 했어. 이유는 [이유]야.

지금이 1년 뒤이고, 이 결정은 완전히 실패했다고 가정해 줘.
1. 실패한 이유를 가능성이 높은 순서로 5개 써 줘. 뻔한 것 말고 내가 놓쳤을 만한 것 위주로.
2. 각 이유마다 지금 알아챌 수 있는 초기 신호를 하나씩 알려 줘.
3. 마지막으로, 내가 직접 생각해 보지 않은 실패 이유가 있는지 나에게 물어 줘.
```

### B2. 반대 고려하기
**근거:** Lord, Lepper & Preston (1984); 적극적 열린 사고 (Baron, 1985; Tetlock & Gardner, 2015)

```
나는 [주장/믿음]이 맞다고 꽤 확신해. 확신 정도는 [ ]%야.

1. 내가 틀렸다면 세상이 어떻게 보여야 하는지 구체적으로 묘사해 줘.
2. 그 상황이 실제로 맞다는 증거가 될 만한 것 3가지를 알려 줘.
3. 이걸 보고 내 확신을 몇 %로 바꿔야 할지 내가 다시 판단하게 물어 줘.
```

### B3. 기준점 확인 (외부 관점)
**근거:** 계획 오류와 외부 관점 (Kahneman & Tversky, 1979; Kahneman, *Thinking, Fast and Slow*, 2011)

```
나는 [계획]이 [기간/비용/확률] 안에 될 거라고 예상해.

1. 이것과 비슷한 일들이 일반적으로 어떤 결과를 내는지 "기준점(base rate)"을 알려 줘.
   확실하지 않은 수치는 확실하지 않다고 표시해 줘.
2. 내 예상이 그 기준점보다 낙관적인지 비관적인지 비교해 줘.
3. 내 경우가 평균과 다르다고 믿을 근거가 있는지 나에게 물어 줘.
```

### B4. 친구에게 조언하기
**근거:** 솔로몬의 역설 (Grossmann & Kross, 2014)

```
내 고민을 3인칭으로 쓸게.
"[이름]은 지금 [상황]이다. [이름]은 [선택지]를 놓고 고민하고 있다."

1. 이 사람에게 지혜로운 조언자라면 어떤 질문을 할지 3개만 말해 줘.
2. 이 사람이 놓치고 있을 수 있는 관점(다른 사람의 입장, 장기적 관점, 불확실성)을 짚어 줘.
조언 자체보다 질문에 집중해 줘.
```

## C. 깊은 이해 (월간 에세이와 함께)

### C1. 철인 논증 (Steelman)
**근거:** 래퍼포트 규칙 (Dennett, 2013); 이념적 튜링 테스트 (Bryan Caplan, 2011)

```
나는 [주장]이라고 생각해.

1. 이와 반대되는 입장을 그 입장의 가장 똑똑한 지지자가 쓴 것처럼 가장 강하게 써 줘.
2. 그다음, 내가 그 반대 입장을 정확히 이해했는지 확인하게
   "반대 입장을 네 말로 요약해 봐"라고 나에게 요청해 줘.
3. 내 요약을 보고 빠진 부분이나 왜곡한 부분을 지적해 줘.
```

### C2. 논증 구조 점검
**근거:** Toulmin 논증 모델 (Toulmin, 1958)

```
아래는 내 에세이 초안이야.
[초안 붙여 넣기]

Toulmin 모델로 분석해 줘.
- 주장(Claim):
- 근거(Grounds):
- 연결 고리(Warrant): 드러나지 않은 숨은 전제는?
- 단서(Qualifier): 과하게 일반화한 곳은?
- 반론(Rebuttal): 다루지 않은 강한 반론은?
고쳐 쓰지 말고, 각 항목의 약점만 지적해 줘.
```

### C3. 레드팀 리뷰
**근거:** 레드팀 기법 (군사 및 정보 분석 분야); 적극적 열린 사고

```
아래 글을 읽고 비판적인 심사위원 3명의 입장에서 각각 가장 날카로운 비판을 하나씩 해 줘.
1. 이 분야의 전문가
2. 회의적인 실용주의자 ("그래서 뭐가 달라지는데?")
3. 나와 가치관이 정반대인 사람
[글 붙여 넣기]
```

## D. 지혜와 성찰 (주간 회고와 함께)

### D1. AAR 코치
**근거:** After Action Review (미 육군); Di Stefano 외 (2014)

```
이번 주에 있었던 일이야.
[상황 설명]

AAR 4문을 하나씩 나에게 물어 줘. 한 번에 한 질문만.
1. 원래 무엇을 하려고 했나?
2. 실제로 무슨 일이 일어났나?
3. 왜 차이가 생겼나?
4. 다음에 무엇을 유지하고 무엇을 바꿀까?
내가 사실과 해석을 섞어 말하면 지적해 줘.
```

### D2. 지혜로운 추론 점검
**근거:** 지혜로운 추론의 요소 (Grossmann, 2017): 지적 겸손, 다른 관점 인정, 변화 가능성 인정, 타협 모색

```
아래는 내가 겪은 갈등이나 어려운 상황에 대한 내 생각이야.
[내 생각 붙여 넣기]

다음 4가지 기준으로 내 생각을 점검하는 질문을 해 줘.
1. 지적 겸손: 내가 모를 수 있는 것을 인정하고 있나?
2. 다른 관점: 상대방이나 제3자의 시각을 고려했나?
3. 변화 가능성: 상황이 어떻게 달라질 수 있는지 생각했나?
4. 타협과 통합: 양쪽을 아우르는 방법을 찾아봤나?
```

### D3. 패턴 찾기 (월 1회)
**근거:** 결정 일지 검토 (Farnam Street); 성찰적 학습

```
지난 몇 달간 내가 쓴 결정 일지와 회고야.
[기록 붙여 넣기]

1. 내가 반복해서 빠지는 생각 패턴이나 편향이 보이면 근거 문장과 함께 짚어 줘.
2. 내가 반복해서 잘하는 것도 하나 알려 줘.
3. 단정하지 말고 "이렇게 보이는데 맞아?"라고 나에게 확인해 줘.
```

## 피해야 할 사용법

| 이렇게 하지 말고 | 이렇게 |
|---|---|
| "이 주제로 에세이 써 줘" | "내 초안의 가장 약한 논리를 지적해 줘" |
| "어떻게 결정해야 할까?" | "내 결정에 사전 부검을 해 줘" |
| "이 책 요약해 줘" | "내가 쓴 요약에서 빠지거나 틀린 걸 찾아 줘" |
| AI의 답을 그대로 노트에 붙여 넣기 | AI의 질문에 내가 답한 것을 노트에 쓰기 |
| AI의 지적에 모두 동의하기 | 동의하지 않는 지적은 왜 그런지 한 줄 쓰기 |

> **주의:** AI가 말하는 통계나 연구 결과도 틀릴 수 있다. 중요한 사실은 원문을 직접 확인한다.
