# 생각하고 쓰는 루틴

글쓰기와 생각하기로 더 똑똑하고 지혜로운 사람이 되기 위한 루틴 템플릿과 AI 활용 프롬프트 모음.
각 템플릿은 연구 결과나 오래 검증된 기존 템플릿을 바탕으로 만들었고, 근거는 각 파일 하단과 [references.md](references.md)에 정리했다.

## 처음 시작한다면

1. **첫 2주**: 매일 생각 노트만 쓴다. 습관이 붙는 게 먼저다.
2. **3주차부터**: 주간 회고를 추가한다.
3. **결정 일지**: 중요한 결정이 생길 때마다 쓴다. 3개월 뒤 다시 읽는 날을 달력에 적어 둔다.
4. **월간 에세이**: 한 달 동안 쌓인 생각 노트 중 가장 오래 남은 주제 하나를 고른다.

## 모든 템플릿에 공통으로 적용한 원칙

- **먼저 내 머리로, 그다음 AI로.** 생성형 AI에 생각을 일찍 넘기면 연습 성과는 오르지만 실제 실력은 떨어진다는 실험 결과가 있다 (Bastani 외, 2024). 모든 템플릿은 "내가 먼저 쓰는 칸"을 AI 활용보다 앞에 둔다.
- **다시 읽기가 쓰기만큼 중요하다.** 결정 일지와 회고는 다시 읽을 때 배움이 생긴다. 사후 확증 편향(hindsight bias) 때문에 기록하지 않은 과거 판단은 기억 속에서 바뀌기 때문이다 (Fischhoff, 1975).
- **나를 한 발 떨어져서 보기.** 사람은 남의 문제에는 더 지혜롭게 판단하지만 자기 문제에서는 그렇지 못하다 (솔로몬의 역설, Grossmann & Kross, 2014). 회고와 결정 일지에 "친구에게 조언한다면?" 칸을 넣은 이유다.
- **효과에 대한 현실적인 기대.** 쓰기를 통한 학습 효과는 메타분석상 "작지만 확실한" 수준이다. 몇 번 써서 달라지기보다 몇 달 꾸준히 쓸 때 쌓인다.
