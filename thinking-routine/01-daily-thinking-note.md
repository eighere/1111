# 매일 생각 노트 (10~15분)

> 목적: 머릿속에 흐릿하게 떠다니는 생각을 하루 하나씩 선명한 문장으로 바꾼다.

## 템플릿

복사해서 쓰세요. 모든 칸을 채울 필요는 없지만 **1번과 3번은 꼭** 쓴다.

```markdown
# 생각 노트 YYYY-MM-DD

## 1. 오늘 붙잡은 생각 하나
(읽은 것, 들은 것, 겪은 것 중 마음에 걸린 것 하나. 출처가 있으면 적는다)

## 2. 내 말로 다시 쓰기
(인용하지 말고, 처음 듣는 친구에게 설명하듯 내 말로 3~5문장)

## 3. 한 문장으로 하면
> 

## 4. 왜 그렇게 생각하나? (왜를 세 번)
- 왜? →
- 그건 왜? →
- 그건 또 왜? →

## 5. 막힌 곳
(설명하다 막힌 부분 = 내가 아직 모르는 부분. 질문 형태로 적는다)
- ?

## 6. 연결
(예전에 쓴 노트나 아는 생각 중 이것과 이어지거나 부딪히는 것)
- [[예전 노트 제목]] — 어떻게 연결되나:
```

## 쓰는 법

- **10분 타이머를 맞춘다.** 짧아야 매일 할 수 있다.
- **2번에서 원문을 보지 않는다.** 보지 않고 떠올려 쓰는 것이 핵심이다 (아래 근거의 인출 연습).
- **5번이 비어 있으면 다시 2번을 쉬운 말로 써 본다.** 막힌 곳이 없다는 건 대개 충분히 파고들지 않았다는 뜻이다.
- **6번 연결은 한 개면 충분하다.** 연결이 쌓이면 나중에 월간 에세이의 재료가 된다.
- 주말 회고 때 이번 주 노트의 3번(한 문장)만 모아 읽는다.

## 이 템플릿의 근거

| 항목 | 근거 | 내용 |
|---|---|---|
| 쓰기 자체 | **Bangert-Drowns, Hurley & Wilkinson (2004)** 메타분석 | 학교 기반 "쓰기를 통한 학습" 프로그램 48개를 분석한 결과, 효과는 작지만 긍정적이었다. 특히 **"내가 무엇을 이해했고 무엇을 헷갈리는지" 돌아보게 하는 메타인지 질문**이 들어갈 때 효과가 컸다. → 5번 "막힌 곳" 칸 |
| 내 말로 다시 쓰기 | **생성 효과** (Slamecka & Graf, 1978) | 읽기만 한 정보보다 스스로 만들어 낸 정보를 더 잘 기억한다. → 2번 |
| 보지 않고 쓰기 | **인출 연습** (Roediger & Karpicke, 2006) | 같은 시간 동안 다시 읽은 집단보다, 떠올려 쓴 집단이 1주일 뒤 훨씬 더 많이 기억했다. → 2번 쓰는 법 |
| 왜를 묻기 | **자기 설명 효과** (Chi 외, 1989; 1994) | 공부하면서 "왜 이렇게 되지?"를 스스로 설명한 학생들이 이해와 문제 해결에서 더 좋은 성과를 냈다. → 4번 |
| 쉬운 말로 설명 | **파인만 기법** (리처드 파인만의 학습법으로 알려짐) | 쉬운 말로 설명하다 막히는 곳이 이해의 빈틈이다. → 2번, 5번 |
| 한 생각씩, 연결 | **제텔카스텐** (니클라스 루만; Sönke Ahrens, *How to Take Smart Notes*, 2017) | 루만은 약 9만 장의 메모를 "한 장에 한 생각, 내 말로, 다른 메모와 연결" 원칙으로 쌓아 70권 넘는 책을 썼다. → 1번, 6번 |
| 매일 짧게 | **표현적 글쓰기** (Pennebaker & Beall, 1986) | 하루 15~20분 정도의 짧은 글쓰기도 반복하면 효과가 있다는 연구 전통. 다만 메타분석(Frattaroli, 2006)에서 효과 크기는 작았다. |

참고 템플릿: 줄리아 캐머런의 **모닝 페이지**(*The Artist's Way*, 1992, 아침에 손으로 세 페이지 자유롭게 쓰기)는 생각을 비우는 데 좋고, 이 노트는 생각을 **좁혀서 선명하게 만드는** 데 초점을 둔다. 둘 중 하나를 고르거나 모닝 페이지 뒤에 이 노트의 3번만 붙여도 된다.
